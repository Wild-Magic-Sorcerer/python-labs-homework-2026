### Задание №1

Создайте лямбда-функцию, которая принимает целое число и возвращает:

    "positive even", если число положительное и чётное;

    "positive odd", если число положительное и нечётное;

    "negative", если число отрицательное;

    "zero", если число равно нулю.

Примените её к списку, полученному от пользователя (с проверкой типов) и выведите пары «число — результат» в удобном формате.

### Задание №2

Пусть пользователь имеет возможность формировать список стандартизированных словарей с информацией о товарах в магазине:


	products = [
    {"name": "Laptop", "price": 89990, "discount": 10},
    {"name": "Mouse", "price": 2490, "discount": 15},
    {"name": "Keyboard", "price": 5490, "discount": 0},
    {"name": "Monitor", "price": 27990, "discount": 25},
]

С помощью map и лямбда-функции получите список словарей, в котором для каждого товара добавлено поле "final_price" — цена с учётом скидки. Исходные словари не изменяйте.

Выведите итоговый список и отсортируйте его по возрастанию final_price.

### Задание №3

Создайте список из 20 случайных целых чисел в диапазоне от -100 до 100. Используя filter и лямбда-функцию, получите:

    числа, которые делятся на 3, но не делятся на 9;

    числа, абсолютное значение которых больше 20;

    числа, которые одновременно удовлетворяют обоим условиям.

Выведите три отдельных списка и их длины.

### Задание №4 

Напишите программу, которая получает от пользователя список строк и, используйя filter, map и reduce:

    Оставляет только слова длиной не менее 7 символов.

    Преобразует каждое оставшееся слово в пару (слово, длина).

    Находит слово с максимальной длиной.

    Считает суммарное количество букв во всех отфильтрованных словах.

Программа должна вывести промежуточные и итоговые результаты.

### Задание №5

Реализуйте декоратор, который:

    вызывает декорируемую функцию n раз;

    перед вызовом каждого запуска выводит сообщение (на ваше усмотрение);

    возвращает список результатов всех вызовов.

Примените декоратор к любой функции на ваше усмотрение и продемонстрируйте её вызов.
