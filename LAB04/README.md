### Задание №1

Создайте класс `Transport`. В нём должны быть прописаны:

    приватные атрибуты скорости и ёмкости транспорта;

    свойства класса, позволяющие прочитать значения переменных;

    валидация значений скорости и ёмкости;

    метод, возвращающий строку с основными характеристиками;

    метод, возвращающий True, если скорость превысила произвольную отметку;

    классовый метод*, создающий объект этого класса из словаря.

Создайте классы `Bus`, `Truck` и `Taxi`, наследующие `Transport`:

    Bus добавляет возможность создавать и читать маршрут;

    Truck добавляет грузоподъёмность и метод расчёта стоимости перевозки;

    Taxi добавляет тариф и метод расчёта стоимости поездки.

Продемонстрируйте следующее:

    создание объектов через конструктор и через метод (см. *);

    попытку задать недопустимую скорость или вместимость;

    вызов методов без создания объекта;

    полиморфный вызов методов для списка разных транспортных средств.

### Задание №2

Создайте класс `BankAccount` со следующими требованиями:

    приватные поля баланса, владельца и истории транзакций ТОЛЬКО ДЛЯ ЧТЕНИЯ;

    методы для пополнения и снятия суммы денег с аккаунта;

    проверка корректных значений по операциям;

    запись каждой успешной денежной операции в историю;

    метод, возвращающий копию истории, а не сам внутренний список;

    возможность создать объект класса при помощи публичного метода.

Создайте класс `SavingsAccount`, наследующий `BankAccount`. Он дополнительно имеет следующие пункты:

    добавляет процентную ставку;

    метод, который начисляет проценты на текущий баланс;

    переопределяет метод снятия денег так, чтобы со сберегательного счёта нельзя было снять более 50% баланса за одну операцию.

Продемонстрируйте:

    корректные пополнение и снятие;

    ошибки при отрицательной сумме и превышении баланса;

    невозможность изменить баланс напрямую;

    вывод истории операций;

    полиморфное поведение метода снятия денег для обычного и сберегательного счёта.
### Задание №3

Создайте класс `Person`. В нём должны быть:

    поля имени, пола и возраста (значения нужно валидировать!);

    метод, позволяющий красиво представить человека (выдать информацию о нём);

    метод, позволяющий оценить совершеннолетие человека;

    классовый метод, позволяющий сконструировать персону через переменные.

Создайте класс `Employee`, наследующий Person:

    добавляет значения должности, зарплаты и усреднённых расоходов в месяц (всё с валидацией!);
    
    добавляет абстрактный метод работы,

    добавляет метод, позволяющий оценить приток денег за N месяцев;
    
    если человек тратит в месяц больше, чем получает, он должен умереть;

	позволяет рассчитать, сколько человек скопит денег до пенсии.

Создайте классы `Manager`, `Developer` и `Designer`, наследующие `Employee`:

    Manager имеет список подчинённых и методы, позволящие манипулировать количеством подчинённых. Также он может провести митинг в любой момент для своих подчинённых;

    Developer имеет список языков программирования и метод, который пишет языки программирования на случайном языке;

    Designer имеет список инструментов, которыми он умеет владеть, и метод, позволяющий создавать макеты.

**Каждый класс должен переопределять метод красивого представления и вызывать реализацию родителя через `super()`!!!**

Создайте список сотрудников разных типов и продемонстрируйте:

    полиморфный вызов методов красивого представления;

    полиморфный вызов метода работы, который нужно добавить в базовый класс Employee и переопределить в наследниках;

    корректную работу super() во всей цепочке наследования.
