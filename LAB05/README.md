### Задание №1

Напишите скрипт, который принимает обязательный позиционный аргумент — имя пользователя. Добавьте необязательный аргумент возраста и флаг приветствия. Если возраст указан, выведите его вместе с именем. При использовании флага приветствия, приветствие должно начинаться со слов «Уважаемый(ая)». Проверьте, что возраст является целым числом от 0 до 120. При некорректном возрасте скрипт должен вывести понятное сообщение об ошибке и завершиться с кодом 2.

### Задание №2

Создайте программу, которая принимает два позиционных аргумента — числа x и y. Добавьте необязательный аргумент операции со значениями add, sub, mul или div. Если операция не указана, программа должна просто вывести оба числа. Добавьте аргумент точности, который задаёт количество знаков после запятой в результате. Добавьте аргумент названия файла для сохранения результата выполненной операции. Программа должна корректно обрабатывать деление на ноль и не перезаписывать предыдущую историю.

### Задание №3

Реализуйте скрипт, который принимает один или несколько строковых аргументов. Добавьте флаг подсчёта количества строк, флаг для вывода только уникальных строк и аргумент для вывода строк, длина которых не меньше указанного значения. Добавьте аргумент `--sort` со значениями `asc`, `desc` или `none`. По умолчанию строки должны выводиться построчно. Если указан флаг подсчёта количества строк, выведите только количество строк **ПОСЛЕ** применения фильтров. При пустом списке аргументов или неизвестном значении `--sort` выведите понятное для неуважаемого пользователя сообщение об ошибке.

### Задание №4

Создайте утилиту, которая принимает аргументы `--input` и `--output`. Утилита должна копировать содержимое входного файла в выходной файл. Добавьте необязательный аргумент `--replace` в формате `OLD=NEW`, который заменяет все вхождения строки `OLD` на строку `NEW`. Добавьте необязательный аргумент `--append-footer`, который добавляет указанную строку в конец выходного файла. Добавьте флаг, который разрешает перезапись существующего выходного файла. Программа должна проверять существование входного файла, не перезаписывать выходной файл без флага перезаписи и выводить количество выполненных замен.


### Задание №5

Создайте скрипт для генерации паролей. Он должен принимать аргумент длины пароля, и аргумент количества паролей для генерации. Добавьте флаги (2 шт.), которые исключают цифры или специальные символы из пароля. Добавьте аргумент для сохранения сгенерированных паролей в файл. Программа должна генерировать пароли (по произвольному алгоритму), проверять, что длина пароля находится в диапазоне от 8 до 64, и выводить ошибку, если после исключения символов генерация пароля невозможна.
